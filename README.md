## 📖 Overview

A **21-day coding challenge** documenting my daily Python practice and progress on **Google Colab**.
Dedicated to building **consistency** and **practical coding habits**.

Each day is a self-contained Colab notebook (`python_practice_day_01` … `python_practice_day_21`)
containing the concept, the code, and the executed output — so the repository doubles as a
**personal reference manual** and a **learning log**.

The curriculum is deliberately progressive:

| Phase | Days | Focus |
| :--- | :--- | :--- |
| 🧱 **1. Foundations** | 1–4 | Data types, variables, operators, strings |
| 📦 **2. Collections** | 5–7 | Lists, tuples, sets, dictionaries |
| 🔀 **3. Control Flow** | 8–10 | Conditionals, loops, a working to-do app |
| 🧩 **4. Functions** | 11–12 | Parameters, recursion, lambdas, decorators, generators |
| 🏛️ **5. OOP** | 13–16 | Classes, inheritance, polymorphism, abstraction |
| 🗄️ **6. Real World** | 17–21 | Files, modules, exceptions, email, web scraping, validation |

## ✨ Key Highlights

- **🧪 Learn-by-output** — every concept is followed by executed cells with visible results, so the
  *behaviour* of Python is documented, not just its syntax.
- **🛠️ Four working mini-projects** — a **To-Do List Manager** (Day 10), a **Bank Management
  System** built on an abstract base class (Day 16), an **email sender** (Day 20) and a **User
  Authentication / regex validator** (Day 21).
- **🏛️ OOP end-to-end** — Day 13 classes → Day 14 inheritance → Day 15 polymorphism/duck typing →
  Day 16 applied to a real banking model with a **700 Tk overdraft**.
- **💥 Error-first learning** — Day 19 deliberately triggers `NameError`, `TypeError`, `ValueError`,
  `ZeroDivisionError`, `IndexError`, `KeyError`, `AttributeError`, `FileNotFoundError`,
  `ModuleNotFoundError`, `IndentationError` and `AssertionError`, then shows the fix or the
  `try/except` handler for each.
- **🔁 Before/after debugging** — several notebooks keep the *wrong* version next to the
  *corrected* version (Day 16 especially) to show the debugging process, not just the answer.
- **📓 Zero setup** — pure Python 3 on Colab; no virtualenv, no local install.

## 🚀 Installation & Quickstart

### ✅ Prerequisites

**None.** No Python install, no `pip`, no virtual environment — everything runs in the browser.

### ▶️ Run a day in Google Colab

1. Open [Google Colab](https://colab.research.google.com/) → **File ➔ Upload notebook**.
2. Select any `python_practice_day_XX` file from this repository.
3. Run the cells top-to-bottom with `Shift + Enter`.

### ▶️ Run locally with Jupyter

```bash
git clone https://github.com/mdnafizurrahman8024/Python-Foundation-21-Days.git
cd Python-Foundation-21-Days

# Give the notebooks a real extension so Jupyter recognises them
mv python_practice_day_01 python_practice_day_01.ipynb

pip install notebook
jupyter notebook
```

### 📦 Extra dependencies (Day 20 only)

Only the web-scraping section needs third-party packages:

```bash
pip install requests beautifulsoup4 lxml
```
